日期：2026-10-31。本轮覆盖 Thor 专用壳的方向导航、页面操作菜单、进入／返回列表和退出保护。复用既有账号与播放连接；Legacy 账号兼容页及未来文字输入面板不在本轮重写范围。

后续已补齐选歌自动进入播放页、返回精确滚动位置、搜索提交、提示自动消失与上屏展示焦点隔离；最新源码 `e87ed087` 的 534 项 JVM／54 项原生回归见 [交互修正验证](interaction-refinement-validation.md)。以下保留原轮次记录。

## 最终交互

- 方向键和左摇杆只在当前内容列表或明确登记的选项区域移动。页头、右侧 Tab、页脚、迷你播放条和侧栏的「正在播放」入口均不参与方向焦点。
- 列表按完整稳定 key 序列导航，包括尚未组合的屏外条目；移动时先保存逻辑目标，再滚动和请求原生焦点。连续输入到边界停止，不绕回、不跨到其他区域。
- 新进入列表、队列及每次新提交的搜索结果从首项开始；异步空列表等到数据到达再选首项。返回已有列表恢复有效 key 和滚动位置；原条目删除时退回首项。
- 页面／菜单切换会重置持有输入，旧手势必须释放或归中后才能作用于新区域。进入肩键进度预览保留原有按住、松开提交合同。
- 队列与歌词列表已经删除独立的「定位当前」按钮及其整行占位，列表延展到迷你播放条上方。定位只保留在长 Select 的「页面操作」菜单中。
- 正常 Player 的主焦点只有播放／暂停；显式进度编辑的主焦点只有应用。Appearance、Controls、Timer 仅允许在已声明的选项区移动。
- Home 首次 B 显示「再按一次 B 退出」，2 秒内再次独立按 B 才退出。其他实际输入、触摸、导航、后台或失焦会清除计时；按住重复不算第二次 B。其他一级页 B 先回首页。

| 按键 | 行为 |
|---|---|
| ↑／↓、左摇杆 | 当前列表或明确选项区域内移动 |
| A／B | 确认／逐层返回 |
| X | 当前条目的操作菜单，保留上下、A、B 与左右子菜单操作 |
| L1／R1 | 一级页切 Tab；Player 短按前后 15 秒，按住预览、松开提交 |
| Start | 全局进入／返回播放页 |
| Select 短按 | 松开时进入／返回队列 |
| Select 按住 500ms | 打开「页面操作」，只触发一次，松开不再打开队列 |
| Y | 播放／暂停 |
| L2／R2 | 上／下一首；保持轴归零及数字释放后才重新触发 |
| L3／R3 | 具有真实批量动作的集合页随机播放／播放全部 |

页面操作按当前页面提供分类、搜索／编辑、刷新／重试、导入／扫描、新建歌单、定位，以及 Player 的喜欢、更多、进度、模式、歌词和定时等可执行项。菜单用独立的闭合焦点区域，跳过禁用项，支持屏外选项和快速连续输入；B 关闭后恢复父列表。动作和有效性栅栏使用同一次实时导航、账号与播放快照，关闭后再执行，并拒绝已换页、换账号或换曲的过期动作。

## 实际页面检查

在真机实际首页，通过明确投递到下屏 display 4 的 Android 方向事件，已观察到焦点从首个内容条目移到第三个；焦点不进入侧栏、页头或迷你播放条。退出检查结果：首次 B 后应用仍前台；中间方向操作后再次 B 仍前台；提示后第二次 B 才退出。

最终 APK 的模拟器实际队列页已确认：没有可见的「定位当前」按钮，首行获得原生焦点；列表容器边界为 `[28,129][1212,877]`，下方直接为迷你播放条，删除的独立功能行没有留下空位。该次设备下屏为 1240×1080、369dpi；坐标仅记录此配置，不作为代码常量。

模拟器实际应用中，连续 Down 后焦点仍在队列条目；以投递到下屏的 900ms Select 打开了真实「页面操作」菜单，菜单内保留「定位当前」。最终无线安装后的真机截图也确认，队列首项获得焦点、底部定位行已消失、列表直达迷你播放条上方。真机 UIAutomator 默认导出上屏的树，因此下屏这项以对应物理显示器的原生截图核对。
