# 歌词滚动、渐隐与可视范围验证

日期：2026-10-31。用户要求后续设备测试全部使用双屏专用模拟器；本轮最终 Android 回归、安装与实际窗口核对均在 `thor_agent_dual_api36` / `emulator-5560` 完成。

## 问题与修复

原实现切换当前行时，同时把主文字从 19sp 放大至 28sp、插入译文／发音、按时间插入内嵌伴唱。自动定位使用 `animateScrollToItem`，滚动过程中前序与目标行的高度仍在变化，造成估算位置和 LazyList 锚点补偿交错，可能表现为滚过头再回拉。

现在按每行当前／相邻两种真实样式的测量预留主文字高度，译文与发音提前显示，内嵌伴唱提前留位后只改变透明度。主文字字号改为 24／22、译文仍为 14，减少不同字号产生的换行差异；行间距 16dp、上下内边距各 8dp、行高 1.5em 保留。当前行仍以字重、语义色及逐字进度强调。

已测量的近处目标用实际像素差进行一次 300ms 单调滚动，不再依赖平均行高估算后补偿。首次、远处跳转及减少动态时直接定位。内容 padding 按当前视口与锚点计算，首末行均能进入清晰区域，移除旧固定 260dp 底部留白。手势仍可打断滚动，全部拖动和惯性停止 15 秒后恢复跟随；只有点击歌词会请求从该行播放，浏览与自动滚动不 seek。

右侧歌词改用上下各 5% 的外层 inset，标题间距为 12dp；左侧 CD 盒保留原 13% 可用矩形与位置。歌词顶部 24dp、底部 36dp 使用 `Offscreen + DstIn` 的真实 alpha 渐隐，中央保持清晰，背景流动可透过边缘；没有额外触摸遮挡层。字号、渐隐、锚点、inset 和标题间距均进入共享主题 token，三材质与日夜共用。原型的内嵌 token 已同步，浏览器旧交互不作为原生回归依据。
