# 上屏歌词浏览与排版验证

日期：2026-10-31。设备为实体 AYN Thor `102d7f27`，Android 13 / API 33。上屏仍为 1920 × 1080，整体封面与歌词双栏比例不变。

## 已实现的交互

- 在上屏歌词区域上下拖动，仅移动歌词视口，不修改播放进度。播放时间及当前行高亮仍正常更新。
- 手指、拖动与惯性滚动全部结束后，连续 15 秒无操作，恢复跟随**当时实际播放的位置**。继续操作会作废旧计时并重新开始。
- 单击任意一行，从该行起点继续播放；暂停状态也明确恢复播放。提交前核对当前队列 `entryId`，不替换队列，不让旧歌曲的点击跳转到新歌。
- 正常模式平滑恢复滚动；减少动态时直接定位。拖动可打断跟随动画，后续恢复与播放行推进仍有效。
- 隐藏、退出或换曲后清理浏览状态、旧手势与计时。触摸行的可操作范围包含整行上下留白，最小 48dp。

## 共享排版参数

当前行 / 相邻行 / 译文字号仍为 28 / 19 / 14。句间距为 16dp，每行上下留白各 8dp，原文到辅助文字间距为 8dp，译文与音译等辅助文字组内间距为 6dp，行高为 1.5em。伴唱采用相同的辅助分组规则。

## 最终构建与验证

- Debug 应用及 AndroidTest 安装包构建成功。
- **389 项相关 JVM 测试：0 失败、0 错误、0 跳过。** 范围为 Thor、播放、可读歌词与既有手动滚动状态测试。
- **13 项真机 Android 测试全部通过，用时 39.141 秒。** 包括 8 项上屏歌词、4 项原有视觉控件，以及 1 项主题动画恢复回归。
- 歌词测试覆盖真实 Android 拖动与 fling 不触发 seek、播放时钟推进不夺回视口、完整 15 秒计时、再次操作作废旧计时、整行点击仅回调一次、inactive 禁止操作，以及跟随动画被触摸打断后继续恢复。
- 白天、夜间的人工长句与译文检查包括实际换行、组间距、上下留白及点击行底部 padding；以上 PNG 由通过的测试直接导出。
- 连跑发现主题过渡混用系统纳秒时间与帧时钟原点的问题。现在帧仅作节拍，双屏共享过渡始终采用同一系统单调时钟；独立回归在同一 composition 中明确验证减少动态 `true → false` 并切换主题，最终背景像素符合目标。

测试通过 Android 输入事件驱动真机原生组件，没有执行账号或云端音乐库写入。测试过程曾因设备息屏导致界面不可见；最终结果来自唤醒并保持亮屏后的完整重跑，结束恢复原保持亮屏设置 `0`。
