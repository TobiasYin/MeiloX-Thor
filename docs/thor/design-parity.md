## 主题与动效

六套配色的 33 个设计字段与设计 JSON 精确一致；恢复玻璃、金属夜间的原始反光，移除原生 Raised 按钮错误叠加的 glint。CSS 渐变角度使用实际画布计算，内凹、接触阴影、抬升阴影、上缘高光与下缘暗边分别实现。材质组件只负责绘制，不修改布局、焦点路径或业务。

主题包和 System/Day/Night 独立持久化；上下屏使用同一 180ms 单调时间锚，快速切换从当前插值继续。播放器与外部列表服从同一模式。Thor Activity 自行处理 `uiMode` 配置变化，避免系统夜间切换重建窗口造成短暂异色。兼容登录、绑定和设置沿用原账号实现，套入相同的 Thor 色、字、形；旧 MiniPlayer、过渡层和歌手页在该上下文不再自行覆盖全局模式。外部网站的网页内容仍由网站绘制。

保留吹气固定正向、力度驱动加减速、惯性和近正/背面展示角吸附；直接拖动优先接管，带抬升和浮影变化。录制了原生双向拖动、释放、点击转动与归正。触摸不会遗留大焦点框，键盘焦点提示仍保留。减少动态关闭持续运动并直接切换；减少透明关闭 glint、细纹与盒面反射。
