## 已确认的约束

AYN Thor 为主目标：上屏 1920 × 1080，下屏 1240 × 1080。Retroid Pocket Duo 为次目标：上屏 1920 × 1080，下屏 1280 × 960。设备档与主题分离，预览只整体缩放画布。

下屏承担列表与控制，上屏展示封面、资料和歌词。方向键/左摇杆只在当前列表或显式选项 scope 内移动，不进入右侧 Tab、页头、页脚或迷你播放条。新入列表（含队列）及每次新搜索结果都选首项，返回已有列表恢复稳定 key 与滚动；队列和歌词的「定位当前」唯一入口为长 Select 页面操作菜单，不再保留独立底部按钮。四个一级页仍以 L1/R1 切 Tab，其他一级页 B 先回首页，首页首次 B 提示、两秒内第二次独立 B 才退出；其他实际输入/触摸/导航/后台清退出计时，重复 DOWN 不确认。

短 Select 在松开时切换队列，长 Select 500ms 打开「页面操作」，覆盖分类、搜索、刷新、导入、新建、定位当前，以及 Player 模式/歌词/定时/进度等真实可用按钮。X/触摸长按只打开条目菜单；上下/A/B 的菜单与父子层规则保持。除定位当前统一收至页面操作菜单外，其他触摸 UI 保留，按钮不必靠方向越区抵达。

Player 仅播放/暂停主焦点，A/Y 控制；正常 Player 肩键进度合同保持。显式 seek 仅 Apply 主焦点，A 应用/B 取消、方向左/右±10秒；其中再长按肩键仍可松开提交，进入 seek 不打断肩键 hold。导航和菜单切 scope 则清理持有输入。Appearance、Controls、Timer 只在选项区 Spatial 导航；Name 仅明确编辑区域，Start 可挂起同账号草稿后恢复。L2/R2 保留归零锁存，L3/R3 仅有真实批量动作时生效。喜欢/收藏、持久歌单和临时队列仍为独立状态；3D 模型触摸、气流与收尾归正不改变选曲。

## 预览的边界

浏览器中的曲目和封面是虚构示例，管理状态只保存在预览本地。预览没有接通网易云、真实麦克风或原生双屏窗口，不代表原生实现或真机验收已完成。独立预览需要联网加载其通用图标与展示运行时。

原生开发应复用项目现有账号、登录态、音乐服务、数据库及播放队列，不将预览中的内存模型当作业务实现。开发拆分、接口、实施顺序和验证记录另见本目录的开发计划。

## 原生入口

首批实现位于 `app/src/main/java/com/ljyh/mei/thor/`，启动入口是 `ThorActivity`。它使用现有 `MusicService` 和账号会话，上屏为 Activity，下屏为独立 Presentation；本地喜欢与歌单通过 Room 持久化。主题、显示档与音乐业务分别维护。

本轮输入契约针对 Thor 专用壳；Legacy 账号兼容页继续复用既有实现与返回握手，不新增账号页重写。原生已经接入真实数据；浏览器预览继续作为设计基线。各页是否完成全链验收，以验证记录为准。

## 维护方式

先更新设计契约和 Token，再同步预览。重新生成独立预览时，以 `prototype.fragment.html` 为输入，并保留实际原生实现与设计提案之间的状态区分。设备支持、系统权限与服务能力必须以现有代码和设备验证为准。
